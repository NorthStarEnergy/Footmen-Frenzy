# Twisted Fate — Flaming Raven v45b

Twisted Fate uses Flaming Raven by UgoUgo from the user-supplied Flaming Raven.zip. Model and custom texture are imported unchanged; TBSFRaven.blp uses its required root path. The model includes portrait animations. Hero model scale is 1.0, selection scale 1.3, and walk/run animation speeds 275. Gameplay stats, abilities, attack timing, icons, and script remain unchanged from v45a.

Validated classic MDX format and animation list, all nine texture dependencies (built-in textures resolve through Warcraft's DDS equivalents), object-data framing, archive readback, and byte-identical preservation of unrelated payloads. In-game appearance remains untested.
