Footmen Frenzy Solo v1.7-4: spawn audit and unit stats

Exact map SHA256: BED87DA58BFC33AA38810C939661103DF81D8D413CE1E82E54D50E25D49685DF. Static audit of the extracted compiled script and object data; no Warcraft III playtest performed.

Spawn findings

  • 50-unit cap overshoot: the scheduler allows spawning at count <=50, then creates an entire wave. Two-unit waves can reach 52 of a type. It counts only the current spawn type, not the whole army.
  • Overdrive Undead cap bypass: index 0 checks hfoo counts but FFOD_SpawnType creates ugho for Undead in Overdrive. The generated Ghouls do not count toward that check.
  • Opening mass imbalance: slots 1 and 5 get 85 Footmen each; slots 8 and 12 get 81 each. The first batch is 13 versus 9; all later batches match. This is a definite count difference; whether deliberate balance compensation is unknown.
  • Spawn amount can drop for other players: initialization sets two units per wave. An Overdrive timer expiry loops through all 12 players and sets every player with no remaining Overdrive time to one unit per wave, including other players whose timers were never started.
  • Missing upgrade coverage: SoloFootsSpawnUsesRobs omits indices 29 and 30 (alternate Tauren/Dark Tauren), although the parallel FFGS behavior table includes them. These paths miss the scripted Robs HP/damage bonus.
  • Timing table mismatch: udg_unit_spawnrate is not read by the active solo scheduler. Actual intervals are 8, 5 and 7.5 seconds. FFGS scheduler is disabled and has no startup call; old eight/five/ten triggers have no actions attached. No evidence of duplicate regular spawn timers.

How to read the stats

All 51 regular production records are listed, including duplicate unit IDs in alternate base trees. Base stats before upgrades; damage/bounty include dice. Two units per wave initially: 15/min at 8 seconds, 24/min at 5 seconds, 16/min at 7.5 seconds. If wave size becomes one, halve these rates. Rates exclude caps, production toggles, initial mass and special waves.

Only player slots 1, 5, 8 and 12 run in this scheduler. First eight-second-band deadlines are 6.50, 6.75, 7.00 and 7.25 seconds of the active spawn clock. Other bands unlock through Tech Delay T1, then stagger by 0.25–1.00 seconds. The clock advances only once mass is active. A separate one-time wave at game-time counter 70 adds 15 Footmen per living base at 405 movement speed, without the normal production/cap gate.

Attack upgrade Rhme adds one damage die per level; armor upgrade Rhar adds 2 armor per level. Rhan on indices 1,2,14,34,35,49 adds 100 HP at level 1, then 45 per additional level. Robs on 6,10,11,12,24,25,40,41,42,43 adds the same HP plus 3 damage at level 1 and 2 per additional level. R004 on 3,4,5,15,32,33,46 adds 100 range at level 1, then 55 per additional level. Additional Overdrive-specific abilities/research may alter combat behavior.

*Movement, attack type and abilities show map object overrides. “Inherited” means the map does not supply that field; the installed Warcraft base data supplies it. Range and cooldown are script-configured values. No inherited values have been guessed. all-unit-object-overrides.json includes every field stored for every unit/hero/building object in this map; spawn-stats.json preserves all scripted spawn fields. Hero, summoned and Colossal units are outside this regular-production table.
