Solo v1.7-4 → v1.8 TEST07

Comparison of the bot map Footmen_Frenzy_Solo_v1.7-4.w3x with the newest four-player solo test found: Solo_Foots_v1.8_4P_PRELOAD_TEST07.w3x. This does not refer to the separate 6- or 8-player FFA branches.

Read each changed cell as old → new. A single value means unchanged. All 51 regular-production records are included, preserving alternate base paths. Damage and bounty include dice, before upgrades. The table can be searched by unit name or raw ID.

Main findings

  • Normal wave size changes from 2 to 1. Actual spawn intervals remain 8, 5 and 7.5 seconds, so initial sustained normal production is halved across all units.
  • Burning Archer HP changes from 570 to 550 on both production paths. Its interval remains 5 seconds: initial production changes from 24/min to 12/min. It still produces 50% faster than Riflemen/Headhunters and 60% faster than Archers/Banshees.
  • Overdrive in TEST07 temporarily produces 2 per wave and resets only its owner to 1. In v1.7-4, an expiry can reduce other players to 1 too. Therefore the old 2-per-wave column describes initial production, not a guarantee for the entire game.
  • The active solo scheduler still uses fixed intervals. TEST07 contains a different FFGS interval table (e.g. 6.25 seconds for Burning Archer), but FFGS_SchedulerStart has no call site. Those settings are not the active spawn rates.
  • The normal unit cap remains 50 of the current spawned type. TEST07 clamps each wave to remaining capacity and counts the actual selected spawn type. The unused FFGS settings say 60; this does not change the active cap.

Upgrade formulas

In both compiled solo spawn helpers, Rhme adds one attack die per level and Rhar adds 2 armor per level. Rhan adds 100 HP at level 1 then 45 per additional level; Robs adds the same HP plus 3 base damage at level 1 then 2 per additional level. R004 adds 100 range at level 1 then 55 per additional level. Rhan applies to indices 1,2,14,34,35,49 and Robs to 6,10,11,12,24,25,40,41,42,43 in both maps. R004 eligibility changes: old indices 3,4,5,15,32,33,46 become 4,5,15,32,33,46 in TEST07. Thus Archer index 3 loses this scripted range-upgrade bonus; alternate Archer index 31 was excluded in both. HP multiplier is 1.00 in both initializations. Mode-specific research/abilities may add other effects.
