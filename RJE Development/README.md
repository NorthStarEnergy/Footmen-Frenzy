# RJE Development

Retired hero scripts and objects are in Heroes. Casino, bets, minigames, profiles, skins and former Info pages are in UI Development Work. The map builder reads only the active project sources. Each family folder preserves its own implementation.

The current Info menu opens match stats and contains the spell and item hotkey editor. Mundo, Demon Knight, Veigar and Twisted Fate are retired from all active maps. Their saved implementations are under Heroes.
