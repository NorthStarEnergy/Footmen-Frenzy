# Arena 1v1

Accept a challenge and fight with a hero and 40 footmen per side in a separate arena. The 799X version supports free duels and matched wallet stakes.

[799X](799x/) · [Solo Foots](solo/)

The 799X and Solo Foots folders contain the invitations, army setup, arena boundaries, victory checks and cleanup. A hero and its footmen appear for each side when a duel starts.
