# Random boots and amulet recipes

Random-hero reward boots sell for 75 gold. Existing boot movement behavior is preserved, including Mini stacking movement handling.

Recipes consume the normal starting amulet first. Boots of Speed can substitute only when the same hero carries a completed starting-amulet upgrade; that upgrade is retained. Dropping all amulets blocks substitution. Shop boots retain their existing prices.

All five maps passed 1,200 mocked recipe behavior scenarios plus reward inventory/drop checks, JASS compilation, archive roundtrip checks, installed-copy SHA256 verification, and preservation of previous maps. No live gameplay testing was performed.
